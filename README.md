# London-Bike-Sharing-Demand-Analysis

Analyzed London’s public bike-sharing ride data to uncover usage trends and the impact of weather on ridership. Tracked ride volume over time using a 20-week moving average (totaling 5.6M+ rides across the analysis period), and built a temperature-vs-wind-speed matrix to identify optimal riding conditions — ridership peaked in the 12–18°C range with low-to-moderate wind speeds, dropping off sharply in extreme heat, cold, or high wind.

Tools & Skills: Python, Excel, pandas, data visualization, exploratory data analysis, time-series analysis
